START THE PROJECT (3 COMMANDS)
------------------------------
1. .\.venv\Scripts\Activate.ps1
2. python run.py
3. Open: http://127.0.0.1:8000

FIRST TIME SETUP (4 COMMANDS)
------------------------------
1. python -m venv .venv
2. .\.venv\Scripts\Activate.ps1
3. pip install -r requirements.txt
4. python train_phishing_model.py

TRAIN MODELS
------------
Fraud:      python -c "from backend.app.services.training_service import train; train('creditcard.csv')"
Phishing:   python train_phishing_model.py

CHECK STATUS
------------
API:        curl http://127.0.0.1:8000/api/v1/health
Models:     curl http://127.0.0.1:8000/api/v1/models/status

TEST PREDICTION (cURL)
----------------------
