2. STARTING THE APPLICATION
================================================================================

A. Start the Server
-------------------
Method 1 (Recommended - using run.py):
    python run.py

Method 2 (Direct uvicorn):
    uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload

Method 3 (Without reload - production):
    uvicorn backend.app.main:app --host 127.0.0.1 --port 8000


B. Access the Application
--------------------------
    Frontend (Web UI):
        http://127.0.0.1:8000

    API Documentation:
        http://127.0.0.1:8000/docs          (Swagger UI)
        http://127.0.0.1:8000/redoc         (ReDoc)

    Health Check:
        http://127.0.0.1:8000/api/v1/health


C. Stop the Server
------------------
    Press Ctrl + C in the terminal

8. TROUBLESHOOTING
================================================================================

A. Port Already in Use
-----------------------
Problem: "Address already in use" error

Solution 1 - Find and kill process:
    # Windows PowerShell
    netstat -ano | findstr :8000
    taskkill /PID <PID> /F

Solution 2 - Use different port:
    uvicorn backend.app.main:app --host 127.0.0.1 --port 8001


B. Module Not Found Error
--------------------------
Problem: "ModuleNotFoundError: No module named 'backend'"

Solution:
    # Make sure you're in project root directory
    cd "c:\Users\nobin\OneDrive\Documents\Projects\fraud detection"
    
    # Ensure virtual environment is activated
    .\.venv\Scripts\Activate.ps1
    
    # Reinstall dependencies
    pip install -r requirements.txt


C. Model Not Found
------------------
Problem: "No trained model is available"

Solution:
    # Train the required model
    python train_phishing_model.py
    
    # Or train fraud model
    python -c "from backend.app.services.training_service import train; train('creditcard.csv')"


D. CORS Error in Browser
-------------------------
Problem: "Access to fetch at '...' from origin '...' has been blocked by CORS"

Solution:
    # CORS is configured in backend/app/config.py
    # Make sure ORIGIN matches your frontend URL


E. Database Locked
------------------
Problem: "database is locked"

Solution:
    # Close any open database connections
    # Restart the server
    # If persistent, delete app.db and restart (will lose prediction history)


F. Import Error
---------------
Problem: "ImportError: cannot import name '...'"

Solution:
    # Clear Python cache
    python -c "import shutil; shutil.rmtree('__pycache__', ignore_errors=True)"
    python -c "import shutil; shutil.rmtree('backend/__pycache__', ignore_errors=True)"
    
    # Restart server


G. Out of Memory During Training
---------------------------------
Problem: Training crashes with memory error

Solution:
    # Train one model at a time
    # Reduce dataset size temporarily
    # Close other applications
    # Reduce n_estimators in Random Forest


H. Permission Denied
--------------------
Problem: "PermissionError: [WinError 5] Access is denied"

Solution:
    # Run PowerShell/Command Prompt as Administrator
    # Or change file permissions
    # Check if file is open in another program
