🚀 START THE APPLICATION
-------------------------
1. cd "c:\Users\nobin\OneDrive\Documents\Projects\fraud detection"
2. .\.venv\Scripts\Activate.ps1
3. python run.py
4. Open: http://127.0.0.1:8000


📊 ANALYZE TRANSACTIONS (Fraud Detection)
------------------------------------------
1. Go to: Analyze page
2. Select: "Transaction fraud"
3. Load sample: Click "Load Sample Transaction"
4. Choose: "Legitimate Example" OR "Fraud Example"
5. Click: "Run risk assessment"
6. Result: See prediction, risk level, probability

Features: Time, V1-V28 (anonymized PCA), Amount
Model: Logistic Regression (99.9% accuracy)
Dataset: 284,807 credit card transactions


🔗 ANALYZE URLs (Phishing Detection)
-------------------------------------
1. Go to: Analyze page
2. Select: "Phishing URL"
3. Paste URL: e.g., http://192.168.1.100/login
4. Click: "Extract Features"
5. Click: "Run risk assessment"
6. Result: See if URL is legitimate or phishing

Features: 22 URL characteristics (auto-extracted)
Model: Decision Tree (96.5% accuracy)
Dataset: 116,600 phishing URLs


📡 API ENDPOINTS
----------------
# Get feature schema
GET  /api/v1/models/features?task=fraud
GET  /api/v1/models/features?task=phishing

# Make predictions
POST /api/v1/predict/transaction
POST /api/v1/predict/phishing
POST /api/v1/analyze/url  (URL auto-extraction)

# Check status
GET  /api/v1/health
GET  /api/v1/models/status
GET  /api/v1/models/evaluation?task=fraud
